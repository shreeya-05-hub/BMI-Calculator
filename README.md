# 🏋️ BMI Calculator Project

A clean, lightweight, and user-friendly command-line **BMI (Body Mass Index) Calculator** application built using **Python**. This project helps users quickly calculate their body mass index based on weight and height, and instantly categorizes them into health tiers like Underweight, Normal weight, Overweight, or Obese.

## 📖 1. About the Project
Maintaining a healthy lifestyle starts with tracking your basic health metrics. The BMI Calculator provides a simple command-line interface to compute body mass index efficiently using standard height and weight inputs. It takes the guesswork out of health tracking by giving immediate, category-based feedback.

---

## ✨ 2. Key Features
* **Accurate BMI Calculation:** Computes precise BMI values using standard metric formulas.
* **Health Categorization:** Automatically classifies the calculated BMI into Underweight, Normal weight, Overweight, or Obese.
* **Input Validation:** Handles invalid numbers and negative inputs gracefully to prevent program crashes.
* **Simple Interface:** Clean, interactive terminal prompts for seamless user experience.
